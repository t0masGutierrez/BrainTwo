### dynamics
- study of how forces affect the motion of objects

---
### dynamics formula
$$
\begin{aligned}
\vec F _ { A } \rightarrow \vec x _ { A } = ?
\end{aligned}
$$

---
### force
- vector quantity of push or pull on object
![[4 Physics/Images/force.png|300]]

---
### force formula
$$
\begin{aligned}
\vec F = F _ { x } \hat i + F _ { y } \hat j \\
F = \sqrt { F _ { x } ^ { 2 } + F _ { y } ^ { 2 } } \\
\theta = \arctan ( \frac { F _ { y } } { F _ { x } } ) \\
F _ { x } = F \cos ( \theta ) \\
F _ { y } = F \sin ( \theta ) \\
F = \text { force } \\
\hat i = \text { x direction } \\
\hat j = \text { y direction } \\
\theta = \text { angle between vectors }
\end{aligned}
$$

---
### net force
- vector sum of all forces acting on object
![[4 Physics/Images/net force.png|300]]

---
### net force formula
$$
\begin{aligned}
\vec F _ { net } = \sum _ { n } \vec F _ { n } = ( \sum _ { n } F _ { nx } ) \hat i + ( \sum _ { n } F _ { ny } ) \hat j \\
\vec F = \text { force } \\
\hat i = \text { x direction } \\
\hat j = \text { y direction } \\
\end{aligned}
$$

---
### normal force
- perpendicular force by surface on object
![[4 Physics/Images/normal force.png|300]]

---
### normal force formula
$$
\begin{aligned}
\vec F _ { N } = m \vec a _ { N } \\
m = \text { mass } \\
\vec a = \text { acceleration }
\end{aligned}
$$

---
### friction force
- resistive force by surface on object
- static friction acts on stationary objects
- kinetic friction acts on sliding objects
![[4 Physics/Images/friction force.png|300]]

---
### friction force formula
$$
\begin{aligned}
\vec f _ { s } \le \mu _ { s } \vec F _ { N } \\
\vec f _ { k } = \mu _ { k } \vec F _ { N } \\
\mu _ { s } = \text { static friction coefficient } \\
\mu _ { k } = \text { kinetic friction coefficient } \\
\vec F = \text { force }
\end{aligned}
$$

### spring force
- restoring force by spring on object
![[4 Physics/Images/spring force.png|300]]

---
### spring force formula
$$
\begin{aligned}
\vec F _ { s } = - k \Delta \vec x \\
k = \text { spring constant } \\
\vec x = \text { position }
\end{aligned}
$$

---
### drag force
- resistive force by fluid on object

---
### drag force formula
$$
\begin{aligned}
\vec F _ { d } = - k \vec v \\
\vec F _ { d } = \frac { - 1 } { 2 } \rho C _ { d } A \vec v ^ { 2 } \\
k = \text { linear drag coefficient } \\
\vec v = \text { velocity } \\
\rho = \text { density } \\
C _ { d } = \text { drag coefficient } \\
A = \text { cross-section area }
\end{aligned}
$$

---
### buoyant force
- upward force by fluid on immersed object

---
### buoyant force formula
$$
\begin{aligned}
\vec F _ { b } = \rho _ { f } V _ { f } \vec g \\
\rho _ { f } = \text { fluid density } \\
V _ { f } = \text { fluid volume } \\
\vec g = \text { gravity }
\end{aligned}
$$

### free body diagram
- draw body as the origin of the coordinate system
- sketch all forces acting on the body as vectors
- resolve all vectors into scalar components
- if equilibrium then newtons first law $\sum F = 0$ 
- if nonequilibrium then newtons second law $\sum F = m a$ 
![[4 Physics/Images/free body diagram.png|200]]

### gravitational interaction
- responsible for the attraction between masses

---
### gravitational interaction formula
$$
\begin{aligned}
\vec F _ { G } = G \frac { m _ { 1 } m _ { 2 } } { r ^ { 2 } } \hat r \\
G = \text { gravitational constant } \\
m = \text { mass } \\
r = \text { distance between centers } \\
\hat r = \text { direction }
\end{aligned}
$$

---
### electromagnetic interaction
- responsible for the attraction/repulsion between electric charges

---
### electromagnetic interaction formula
$$
\begin{aligned}
\vec F _ { EM } = q ( \vec E + \vec v \times \vec B ) \\
q = \text { electric charge } \\
\vec E = \text { electric field } \\
\vec v = \text { velocity } \\
\vec B = \text { magnetic field }
\end{aligned}
$$

### newtons first law
- object at rest remains at rest or moves with constant velocity unless acted on by nonzero net external force
![[4 Physics/Images/newtons first law.png]]

---
### newtons 1st formula
$$
\begin{aligned}
\vec F _ { net } = 0 \implies \vec a = 0 \\
\vec F = \text { force } \\
\vec a = \text { acceleration }
\end{aligned}
$$

---
### newtons second law
- acceleration dependent mass and net external force acting on mass
![[4 Physics/Images/newtons second law.png]]

---
### newtons 2nd formula
$$
\begin{aligned}
\vec F _ { net } = m \vec a =
\begin{cases}
F _ { x } = m a _ { x } \\
F _ { y } = m a _ { y }
\end{cases} \\
m = \text { mass } \\
\vec a = \text { acceleration } \\
F = \text { force }
\end{aligned}
$$

---
### newtons third law
- for every action force there exists equal and opposite reaction force
- equal magnitude and opposite direction
![[4 Physics/Images/newtons third law.png|200]]

---
### newtons 3rd formula
$$
\begin{aligned}
\vec F _ { AB } = - \vec F _ { BA } \\
\vec F = \text { force } \\
A , B = \text { object }
\end{aligned}
$$
