### position
- location as function of time

---
### position formula
$$
\begin{aligned}
x = x ( t ) \\
t = \text {time}
\end{aligned}
$$

---
### distance
- scalar length of path
![[4 Physics/Images/distance.png|300]]

---
### distance formula
$$
\begin{aligned}
d = \sum _ { n } | \Delta x _ { n } | \\
x = \text {position}
\end{aligned}
$$

---
### displacement
- vector change of position
![[4 Physics/Images/displacement.png|300]]

---
### displacement formula
$$
\begin{aligned}
\Delta x = x - x _ { 0 } = \int v \cdot d t \\
x = \text {position} \\
t = \text {time} \\
v = \text {velocity}
\end{aligned}
$$

---
### average speed
- distance per time

---
### average speed formula
$$
\begin{aligned}
s _ { avg } = \frac { d } { \Delta t } \\
d = \text {distance} \\
t = \text {time}
\end{aligned}
$$

---
### instantaneous speed
- rate of change of distance as change of time approaches zero

---
### instantaneous speed formula
$$
\begin{aligned}
s = | v | \\
v = \text {velocity}
\end{aligned}
$$

---
### average velocity
- position per time

---
### average velocity formula
$$
\begin{aligned}
v _ { avg } = \frac { \Delta x } { \Delta t } \\
x = \text {position} \\
t = \text {time}
\end{aligned}
$$

---
### instantaneous velocity
- rate of change of position as change of time approaches zero
![[4 Physics/Images/instantaneous velocity.png|300]]

---
### instantaneous velocity formula
$$
\begin{aligned}
v = \frac { dx } { dt } = v _ { 0 } + \int a \cdot d t \\
x = \text {position} \\
t = \text {time} \\
v = \text {velocity} \\
a = \text {acceleration}
\end{aligned}
$$

---
### average acceleration
- velocity per time

---
### average acceleration formula
$$
\begin{aligned}
a _ { avg } = \frac { \Delta v } { \Delta t } \\
v = \text {velocity} \\
t = \text {time}
\end{aligned}
$$

---
### instantaneous acceleration
- rate of change of velocity as change of time approaches zero
![[4 Physics/Images/instantaneous acceleration.png|300]]

---
### instantaneous acceleration formula
$$
\begin{aligned}
a = \frac { dv } { dt } = \frac { d ^ { 2 } x } { d t ^ { 2 } } \\
v = \text {velocity} \\
t = \text {time} \\
x = \text {position}
\end{aligned}
$$

---
### delta speed property
- if direction of velocity equal direction of acceleration then increasing speed
- if direction of velocity not equal direction of acceleration then decreasing speed
![[4 Physics/Images/changing speed.png|300]]

---
### delta speed property formula
$$
\begin{aligned}
\hat v = \hat a \implies v a > 0 \\
\hat v \ne \hat a \implies v a < 0 \\
v = \text {velocity} \\
a = \text {acceleration}
\end{aligned}
$$

### kinematics
- describe motion without explaining the cause of motion

---
### kinematics formula
$$
\begin{aligned}
x , x _ { 0 } , v , v _ { 0 } , a , t = \  ?
\end{aligned}
$$

---
### first law of motion
- relate velocity, initial velocity, acceleration, and time

---
### 1st formula of motion
$$
\begin{aligned}
a ( t ) = a _ { 0 } \implies v = v _ { 0 } + a t \\
a = \text {acceleration} \\
v _ { 0 } = \text {initial velocity} \\
t = \text {time}
\end{aligned}
$$

---
### second law of motion
- relate position, initial position, initial velocity, acceleration, and time

---
### 2nd formula of motion
$$
\begin{aligned}
a ( t ) = a _ { 0 } \implies x = x _ { 0 } + v _ { 0 } t + \frac { 1 } { 2 } a t ^ { 2 } \\
a = \text {acceleration} \\
x = \text {position} \\
x _ { 0 } = \text {initial position} \\
v _ { 0 } = \text {initial velocity} \\
t = \text {time}
\end{aligned}
$$

---
### third law of motion
- relate position, initial position, velocity, initial velocity, and time

---
### 3rd formula of motion
$$
\begin{aligned}
a ( t ) = a _ { 0 } \implies x - x _ { 0 } = \frac { 1 } { 2 } ( v + v _ { 0 } ) t \\
a = \text {acceleration} \\
x = \text {position} \\
x _ { 0 } = \text {initial position} \\
v = \text {velocity} \\
v _ { 0 } = \text {initial velocity} \\
t = \text {time}
\end{aligned}
$$

---
### fourth law of motion
- relate velocity, initial velocity, acceleration, position, and initial position

---
### 4th formula of motion
$$
\begin{aligned}
a ( t ) = a _ { 0 } \implies v ^ { 2 } = v _ { 0 } ^ { 2 } + 2 a ( x - x _ { 0 } ) \\
a = \text {acceleration} \\
v = \text {velocity} \\
v _ { 0 } = \text {initial velocity} \\
a = \text {acceleration} \\
x = \text {position} \\
x _ { 0 } = \text {initial position} \\
\end{aligned}
$$

### free fall
- one-dimensional motion under no other force except gravity
![[4 Physics/Images/free fall.png]]

---
### free fall formula
$$
\begin{aligned}
v = v _ { 0 } - g t \\
y = y _ { 0 } + v _ { 0 } t - \frac { 1 } { 2 } g t ^ { 2 } \\
y - y _ { 0 } = \frac { 1 } { 2 } ( v + v _ { 0 } ) t \\
v ^ { 2 } = v _ { 0 } ^ { 2 } - 2 g ( y - y _ { 0 } ) \\
g = 9.8
\end{aligned}
$$

---
### relative motion
- motion of object A relative to object B
![[4 Physics/Images/relative motion.png|300]]

---
### relative motion formula
$$
\begin{aligned}
x _ { A / B } = x _ { A } - x _ { B } \\
v _ { A / B } = v _ { A } - v _ { B } \\
a _ { A / B } = a _ { A } - a _ { B } \\
x = \text {position} \\
v = \text {velocity} \\
a = \text {acceleration}
\end{aligned}
$$
