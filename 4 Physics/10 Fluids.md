### fluid
- liquid or gas

---
### solid
- definite shape
- definite volume
- vibrational motion
![[4 Physics/Images/solid.png]]

---
### liquid
- indefinite shape
- definite volume
- incompressible fluid
- translational motion
![[4 Physics/Images/liquid.png]]

---
### gas
- indefinite shape
- indefinite volume
- compressible fluid
- random motion
![[4 Physics/Images/gas.png]]

---
### volume
- amount of three dimensional space within object
![[4 Physics/Images/volume.png|500]]

---
### volume formula
$$
\begin{aligned}
\text { cube } = l w h \\
\text { sphere } = \frac { 4 } { 3 } \pi r ^ { 3 } \\
\text { cyclinder } = \pi r ^ { 2 } h
\end{aligned}
$$

---
### density
- measure of compactness
![[4 Physics/Images/density.png|400]]

---
### density formula
$$
\begin{aligned}
\rho = \frac { m } { V } \\
m = \text { mass } \\
V = \text { volume }
\end{aligned}
$$

---
### relative density
- measure of compactness with respect to water

---
### relative density formula
$$
\begin{aligned}
\rho ' = \frac { \rho } { \rho _ { w a t e r } } \\
\rho = \text { density }
\end{aligned}
$$

---
### pressure
- measure of local force
![[4 Physics/Images/pressure.png]]

---
### pressure formula
$$
\begin{aligned}
p = \frac { F _ { \perp } } { A } \\
F = \text { force } \\
A = \text { area }
\end{aligned}
$$

---
### atmospheric pressure
- weight of air column
![[4 Physics/Images/atmospheric pressure.png]]

---
### atmospheric pressure formula
$$
\begin{aligned}
\text { 1 atm } = \text { 101325 Pa }
\end{aligned}
$$

---
### hydrostatic pressure
- weight of fluid column at rest with uniform density
![[4 Physics/Images/hydrostatic pressure.png|250]]

---
### hydrostatic pressure formula
$$
\begin{aligned}
p - p _ { 0 } = \rho g y \\
p _ { 2 } - p _ { 1 } = - \rho g ( y _ { 2 } - y _ { 1 } ) \\
p = \text { pressure } \\
\rho = \text { density } \\
g = \text { gravity } \\
y = \text { position }
\end{aligned}
$$

---
### absolute pressure
- measure of pressure relative vacuum

---
### absolute pressure formula
$$
\begin{aligned}
p _ { a b s } = p _ { g } + p _ { a t m } = \rho g y + p _ { a t m } \\
p _ { g } = \text { gauge pressure } \\
p _ { a t m } = \text { atmospheric pressure } \\
\rho = \text { density } \\
g = \text { gravity } \\
y = \text { position }
\end{aligned}
$$

---
### gauge pressure
- measure of pressure relative atmospheric pressure

---
### gauge pressure formula
$$
\begin{aligned}
p _ { g } = p _ { a b s } - p _ { a t m } = \rho g y \\
p _ { a b s } = \text { absolute pressure } \\
p _ { a t m } = \text { atmospheric pressure } \\
\rho = \text { density } \\
g = \text { gravity } \\
y = \text { position }
\end{aligned}
$$

### pascals principle
- change of pressure within enclosed fluid transmit equally throughout the fluid
![[4 Physics/Images/pascals principle.png|300]]

---
### pascals principle formula
$$
\begin{aligned}
p = \frac { F _ { 1 } } { A _ { 1 } } = \frac { F _ { 2 } } { A _ { 2 } } \\
F = \text { force } \\
A = \text { area }
\end{aligned}
$$

---
### archimedes principle
- buoyant force equal the weight of displaced fluid
![[4 Physics/Images/archimedes principle.png|400]]

---
### archimedes principle formula
$$
\begin{aligned}
\vec F _ { b } = \vec w _ { f } \\
\vec w = \text { weight }
\end{aligned}
$$

---
### apparent weight
- immersed object appear less heavy because of buoyant force

---
### apparent weight formula
$$
\begin{aligned}
\vec w _ { a p p } = \vec w - \vec F _ { b } \\
\vec w = \text { weight } \\
\vec F = \text { force }
\end{aligned}
$$

---
### buoyant force
- upward force by fluid on immersed object because of the pressure imbalance between the top and bottom of immersed object
![[4 Physics/Images/buoyant force.png]]

---
### buoyant force formula
$$
\begin{aligned}
\vec F _ { b } = \rho _ { f } V _ { f } \vec g \\
\rho _ { f } = \text { fluid density } \\
V _ { f } = \text { fluid volume } \\
\vec g = \text { gravity }
\end{aligned}
$$

---
### buoyant force direction property
- if buoyant force greater object weight then floating object
- if buoyant force lesser object weight then sinking object
- if buoyant force equal object weight then suspended object

---
### buoyant force direction property formula
$$
\begin{aligned}
\vec F _ { b } > \vec w \implies \uparrow \\
\vec F _ { b } < \vec w \implies \downarrow \\
\vec F _ { b } = \vec w \implies \leftrightarrow
\end{aligned}
$$

---
### submergence
- fraction of immersed object
![[4 Physics/Images/submergence.png|400]]

---
### submergence formula
$$
\begin{aligned}
S = \frac { \rho } { \rho _ { f } } \\
\rho = \text { density } \\
\rho _ { f } = \text { fluid density }
\end{aligned}
$$

---
### submergence direction property
- if fluid density greater object density then floating object
- if fluid density lesser object density then sinking object
- if fluid density equal object density then suspended object

---
### submergence direction property formula
$$
\begin{aligned}
\rho _ { f } > \rho \implies \uparrow \\
\rho _ { f } < \rho \implies \downarrow \\
\rho _ { f } = \rho \implies \leftrightarrow
\end{aligned}
$$

---
### surface tension
- reducing surface area reduces the number of high-energy surface molecules
- minimizing surface area minimizes potential energy
![[4 Physics/Images/surface tension.png|200]]

---
### surface tension formula
$$
\begin{aligned}
\gamma = \frac { F _ { \parallel } } { L } = \frac { \Delta E } { \Delta A } \\
F = \text { force } \\
L = \text { length } \\
E = \text { mechanical energy } \\
A = \text { surface area }
\end{aligned}
$$

### ideal fluid
- constant density and zero viscosity

---
### ideal fluid formula
$$
\begin{aligned}
\rho = C \\
\mu = 0
\end{aligned}
$$

---
### volume flow rate
- amount of fluid flow through cross-section over time
![[4 Physics/Images/volume flow rate.png|200]]

---
### volume flow rate formula
$$
\begin{aligned}
\frac { d V } { d t } = A v \\
V = \text { volume } \\
t = \text { time } \\
A = \text { cross-section area } \\
v = \text { velocity }
\end{aligned}
$$

---
### continuity
- for incompressible fluid there exists inverse relationship between velocity and area
![[4 Physics/Images/continuity.png|400]]

---
### continuity formula
$$
\begin{aligned}
A _ { 1 } v _ { 1 } = A _ { 2 } v _ { 2 } \\
A = \text { area } \\
v = \text { velocity }
\end{aligned}
$$

---
### bernoulli principle
- for ideal fluid there exists inverse relationship between pressure and velocity
![[4 Physics/Images/bernoulli principle.png|200]]

---
### bernoulli principle formula
$$
\begin{aligned}
p _ { 1 } + \frac { 1 } { 2 } \rho v _ { 1 } ^ { 2 } + \rho g y _ { 1 } = p _ { 2 } + \frac { 1 } { 2 } \rho v _ { 2 } ^ { 2 } + \rho g y _ { 2 } \\
p = \text { pressure } \\
\rho = \text { density } \\
v = \text { velocity } \\
g = \text { gravity } \\
y = \text { position }
\end{aligned}
$$

---
### drag force
- resistive force by fluid on object

---
### drag force formula
$$
\begin{aligned}
\vec F _ { d } = - k \vec v \\
\vec F _ { d } = \frac { - 1 } { 2 } \rho C _ { d } A \vec v ^ { 2 } \\
k = \text { linear drag coefficient } \\
\vec v = \text { velocity } \\
\rho = \text { density } \\
C _ { d } = \text { drag coefficient } \\
A = \text { cross-section area }
\end{aligned}
$$

---
### terminal velocity
- free falling object with constant velocity

---
### terminal velocity formula
$$
\begin{aligned}
\vec w = \vec F _ { d } \implies \vec v = \sqrt { \frac { 2 \vec w } { \rho C _ { d } A } } \\
\vec w = \text { weight } \\
\vec F = \text { force } \\
\vec v = \text { velocity } \\
\rho = \text { density } \\
C _ { d } = \text { drag coefficient } \\
A = \text { cross-section area }
\end{aligned}
$$
